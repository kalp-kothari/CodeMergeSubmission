# CodeMerge V2.0 — Submission Portal

A full-stack submission management platform built independently for **CodeMerge V2.0** during my time as one of the **co-organisers of the hackathon**.

> This portal was independently developed as an initiative to streamline the submission process.

## 🚀 Highlights

- 🔐 **Server-Side Team Verification** — verifies the leader's email against the selected team, preventing unauthorized submissions even when bypassing the frontend.
- 📂 **Secure File Uploads** — private cloud storage with PDF/PPTX validation and 10 MB limits.
- ⚡ **Duplicate Prevention** — one submission per team per round.
- ⏰ **Server-Side Deadline Enforcement** — submissions are rejected after the configured deadline.
- 🛠️ **Admin Dashboard** — search, filter, review and download submissions.
- 📊 **XLSX Export** — easily export submission data for evaluation and records.
- ☁️ **Cloud-Based Architecture** — PostgreSQL database and private cloud storage with independently deployed frontend and backend.

## 🧰 Tech Stack

**Frontend:** React, TypeScript, Vite, Tailwind CSS, React Hook Form, Zod, Axios

**Backend:** Node.js, Express, TypeScript, Prisma, JWT, Multer

**Database & Storage:** Supabase PostgreSQL + Supabase Storage

**Deployment:** Vercel + Render
